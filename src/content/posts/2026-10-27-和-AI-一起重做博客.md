Hexo 版的博客上线没多久，我又在命令行里和 AI 编程助手把整个站重做了一遍。现在你看到的首页、地球、抽屉、搜索都是这一轮的产物。这篇按时间顺序记一下过程，最后一节写写复盘：我和它来回说了太多轮，如果从零开始，一次对话该怎么说才能直接做到现在这样。

## 从 Hexo 搬到 Astro

换框架的理由很简单：我想要的首页交互越来越多，Hexo 的 EJS 模板写起来越来越别扭。Astro 默认输出纯静态页面，需要交互的地方再单独写脚本，正好合适。

旧文章用一个一次性脚本从 Hexo 站抓下来，转成 Markdown 放进 `src/content/posts/`。文件名直接决定地址，`2026-10-10-Spring-Boot-自动配置原理.md` 对应 `/2026/10/10/Spring-Boot-自动配置原理/`，和 Hexo 时期的链接格式一致。

## 用随机种子挑设计方向

样式这块我自己没什么主意，就让 AI 先列一棵决策树：设计流派、布局、排版、配色、组件、材质、信息密度、导航、面板切换、动效、地球呈现，一共 11 个维度，每个维度 6 到 9 个分支。

先过一遍约束。功能、内容和交互都要保留，不要暗黑模式，所以像"赛博暗夜"这种黑底的分支在选择之前就被过滤掉了。剩下的分支用随机种子来选：每个维度算一次 `SHA-256(种子 + 维度名)`，对合法分支数取模，得到这个维度的选择。这样生成 12 组候选，再从里面挑出两两差异最大的 4 组（12 选 4 穷举，最大化最小汉明距离），保证四个方案长得确实不一样。种子和结果都存下来了，同一个种子重算一定得到同样的方案。

四个方案分别是：

| 方案 | 流派 | 布局 | 一句话印象 |
| --- | --- | --- | --- |
| A | 编辑杂志 | 层叠卡片 | 楷体标题，打字机动效，地球从底边探出半个 |
| B | 日式侘寂 | 便当盒网格 | 超大压缩字，森林绿配芥末黄，视差滚动 |
| C | 孟菲斯后现代 | 便当盒网格 | 全站等宽字，灰阶加荧光黄，底部 Dock 和抽屉 |
| D | 复古天文台手册 | 不对称网格 | 宋体，陶土赭石色，命令面板，翻转卡片 |

四个都做成能点能用的页面放在 `/lab/` 下面对比。C 和 D 我都挺喜欢，看了几轮之后定了 C。

## 一轮轮打磨 C

定下方向以后，大部分时间花在细节上。首页是一屏便当盒格子：名字、时钟、最新一篇、技术栈、最近几篇、写作记录、常写的标签。背后是一颗按真实时间算晨昏线的地球，夜里那半边亮着城市灯光，橙色光点标的是西安，可以拖着转，双击转回来。

底部 Dock 上的文章、分类、关于点开是抽屉，地址栏跟着变成 `#posts` 这样的 hash，前进后退和刷新都能停在原来的抽屉。键盘上 P、C、A 开抽屉，J、K 上下选，`/` 在抽屉里过滤，`?` 弹出快捷键说明。从文章返回首页时，抽屉的滚动位置还在，刚读过的那篇会标出来，卡片和文章页之间有一段变形过渡。阅读页有目录、阅读进度、代码复制、相关文章和系列导航，一年以上没更新的文章会在开头提醒一句可能过时。

评论用 giscus，评论存在 GitHub Discussions 里，不需要自己的服务器。不过它要先在 GitHub 上开 Discussions 再生成配置，我还没弄，所以代码里留空，留空时页面不加载任何外部脚本。

中间有一阵改得太多，四个方案各有一堆改动，我自己都看晕了，干脆让它停下来，把要做的决定一条条列出来让我选。之后又请它从产品设计和 UI 的角度挑一遍毛病，按优先级一项项改掉。

## 最后一轮：修 bug，加回搜索，拆成两份

最后一次我把攒下的问题一起丢给它：

首页的地球拖不动了，进了文章页再回来又可以。原因是背景上有一层装饰用的圆形图案盖在画布上面，把鼠标事件吃掉了，加一行 `pointer-events: none` 就好。

之前做过的全站搜索在改版里丢了，这次重新加回来，任何页面按 ⌘K（Windows 上是 Ctrl K）都能打开。标题命中排最前，其次是标签和分类、摘要、正文，空格分隔的多个词要全部命中，结果里把关键词标出来。首页抽屉打开时 `/` 还是只过滤抽屉，其他时候也是打开搜索。

写作记录那一格原来的标题是 `git log --since=1y`，看着像极客彩蛋，但不熟悉 git 的人看不懂，改成了"近 12 个月写了 N 篇"，柱子下面加上起止月份。常写的标签那一格，标签多的时候往上溢出，被标题下面的横线压住了半截，改成两列的小表格，从顶部往下排。分类抽屉里的标签原来挤成一团，现在只显示最常用的 12 个，带篇数，后面跟一个"全部标签"的入口。

顺手改的还有几处：中文标题从等宽字换回无衬线字，长段落读起来舒服些；正文链接加了下划线，悬停时才亮荧光黄；手机上地球那一格缩小，不再占掉大半屏。

改完之后，`/lab/` 下面的四套方案、种子脚本和导入脚本全部删掉，C 搬到正式目录。项目拆成两份：一份是这个博客本身，另一份是去掉个人内容的模板，配置集中在一个文件里，README 写了中英文两版，Mac 和 Windows 的安装、写文章、改配置、部署都在里面，别人拿去改个名字就能用。

## 复盘：如果从零开始，一次对话怎么说

回头看，我和 AI 来回了几十轮，大部分轮次在纠偏：它做了一个我没想要的东西，我再说清楚。有些需求是看到实物才冒出来的，这部分省不掉；但还有不少是我一开始就知道、只是没说出口的，比如不要暗黑模式、要能键盘操作、不能把已有功能改没了。

所以反过来想，如果把这一路积累下来的结论一次说清楚，第一轮就能拿到接近现在的结果。下面这段是我整理的提示词，可以直接贴给命令行里的 AI 编程助手（Claude Code 这一类能读写文件、跑命令的工具）。要换成你自己的，改掉第一段的个人信息就行。

```text
帮我从零做一个个人技术博客，用 Astro（最新版）构建，部署到 GitHub Pages。一次做完，中途不用问我，有拿不准的地方按下面的约定选，做完后自己构建并在浏览器里验证，最后告诉我结果。

【我的信息】
名字 Awen，GitHub 用户名 Awen-9，仓库 Awen-9.github.io，站点 https://awen-9.github.io。
后端开发工程师，在西安（东经 108.94，北纬 34.34，时区 Asia/Shanghai），主要写 Java。
关注后端开发、分布式、高并发；技术栈 Spring、Spring Boot、MyBatis、MySQL、Redis、Kafka；在深入 Spring 源码、JVM、中间件原理。
先写 3 篇示例文章，分类和标签各不相同，其中两篇共享标签。

【硬约束】
只要浅色，不要暗黑模式。不接任何统计。没有配置的外部服务（评论）不能加载任何外部脚本。
所有个人信息集中在 src/config.ts，其他地方不写死名字、城市、仓库。
文章放 src/content/posts/YYYY-MM-DD-slug.md，文件名决定地址 /YYYY/MM/DD/slug/，trailingSlash 用 always。
frontmatter：title、description、date、updated（可选）、category、tags、draft、series（可选）。
所有交互都要能用键盘完成，尊重 prefers-reduced-motion，移动端 390px 宽不能横向溢出。
代码注释用中文，只写为什么，不写废话。不要留下实验目录、备用方案和用不到的依赖。

【视觉风格】
孟菲斯后现代加便当盒网格：浅灰底，纸张颗粒噪点，灰阶为主，荧光黄 #dcff00 和粉色 #ff6fb5 点缀。
格子是索引卡风格：1px 黑细线，顶部一条等宽小字的标签栏（像文件名或终端提示符）。
标签、日期、按钮用等宽字；中文标题和正文用无衬线字（苹方、微软雅黑）。
背景散落几个孟菲斯几何碎片（圆、三角、斜线、波点），只在首页出现。
正文链接带下划线，悬停时亮荧光黄底色。

【首页】
全屏背景是一颗 three.js 地球：按当前真实时间算太阳直射点和晨昏线，白天一面用真彩贴图，夜里一面显示城市灯光，加一层云和高光。
家乡城市标一个橙色光点。地球可以拖动旋转，有惯性，松手几秒后慢慢转回家乡，双击立刻转回。
宽屏时地球偏右，便当盒在左；手机上地球放进格子里，跟着页面滚动。
装饰图层必须 pointer-events: none，不能挡住地球的拖动。
不支持 WebGL 时显示一个虚线圆的占位。贴图分 1k 和 2k，手机和省流量模式用 1k。

便当盒格子：
1. 名字大字，下面一行身份。
2. 时钟：家乡时区的时间、日期、此刻太阳直射点的经纬度。
3. 最新一篇：标题、摘要、分类、阅读时长、标签，整格可点。
4. 技术栈：关注方向、技术栈小方块、在深入什么，链接到关于。
5. 最近三篇。
6. 近 12 个月每月写了几篇的柱状图，标题直接写"近 12 个月写了 N 篇"，下面标起止月份。
7. 常写的标签：两列表格，标签加篇数，从顶部排起，不能溢出到标题栏下面。
格子之间不要大片留白，内容少的格子从上往下排。

底部固定一个 Dock：文章 P、分类 C、关于 A、搜索 ⌘K、RSS R、GitHub G、快捷键 ?，每个按钮带键帽样式的快捷键提示。

文章、分类、关于是从右侧滑出的抽屉（手机上是底部面板，顶部有把手可以下拉关闭）。
抽屉状态写在 URL hash（#posts、#categories、#about），刷新、前进后退都能恢复，页面加载前就要设好，避免闪一下。
抽屉打开时便当盒滑走，地球挪到另一边。点地球空白处关闭抽屉，但拖动后松手不算点击。
文章抽屉按年份分组；分类抽屉顶部是最常用的 12 个标签（带篇数）和"全部标签"入口，下面按分类分组。
抽屉里 J/K 或方向键上下移动，Enter 打开，/ 打开抽屉内过滤（grep: 风格的输入框，同时搜标题和正文），Esc 先清空过滤再关抽屉。
从文章页返回首页时：恢复抽屉滚动位置，标出刚读过的那篇，用 View Transitions 让列表项和文章卡片互相变形。
上次访问之后发的新文章标 new，基准时间在一次会话内固定。
? 弹出快捷键说明卡片，带一个开关可以关掉单键快捷键（照顾读屏和语音输入），桌面只显示键盘说明，触屏只显示手势说明。

【全站搜索】
任何页面 ⌘K / Ctrl K 打开命令面板式的搜索框；子页面上 / 也能打开；首页抽屉打开时 / 留给抽屉过滤。
构建时生成 /search.json（地址、标题、摘要、日期、分类、标签、去掉 Markdown 的正文），第一次打开时才请求。
空格分隔多个词，全部命中才算；排序权重：标题 > 分类和标签 > 摘要 > 正文；正文命中时截取关键词附近一小段。
关键词用 mark 标出，只拼文本节点，不用 innerHTML。上下键选择，Enter 打开，Esc 关闭，点遮罩关闭。
空输入时显示最近 6 篇。非 Mac 系统把 ⌘K 提示改成 Ctrl K，触屏上显示成 /。

【子页面】
文章页、归档、分类、标签、关于、404 共用一个外壳：顶部是站名、文章、分类、关于、RSS、GitHub、搜索按钮，右边"回到首页"（从首页点进来时直接后退，保留抽屉状态）。
文章页：标题、日期、更新日期、分类、阅读时长；宽屏左侧固定目录，读到哪节高亮哪节；小节标题旁有复制链接的 #；顶部阅读进度条；代码块有复制按钮，代码高亮用 github-light；超过一年没更新的文章在开头提醒可能过时。
文末：标签、上一篇下一篇、按共享标签数推荐 3 篇相关文章、同 series 的系列导航、giscus 评论（repoId 和 categoryId 填了才渲染）。
生成 /atom.xml 订阅源。404 页提示可以用 ⌘K 搜索。每页有 canonical 和 og 标签。

【部署】
.github/workflows/deploy.yml：push 到 main 时用 Node 24 构建，upload-pages-artifact 加 deploy-pages 发布。
README 写清楚本地运行、写文章、改配置、开启 giscus、部署到 GitHub Pages 的步骤。

【验收】
npm run build 没有报错和警告。用无头浏览器分别在 1440x900 和 390x844 下截图检查首页、抽屉、搜索、文章页、404，确认：
地球能拖动；⌘K 能搜到正文里的词；抽屉的 hash 在刷新后保留；手机上没有横向滚动条；所有格子里的文字没有被裁切或压线。
发现问题自己修完再交付。
```

这段提示词把我零散提过的要求按页面整理到了一起，比如"拖不动地球"这种 bug 写成了"装饰图层不能挡住地球"的约束，"看不懂 git log"写成了柱状图的标题。还有一条经验：最后一段的验收清单最有用，它让 AI 自己截图检查，不用等我发现问题再告诉它。
