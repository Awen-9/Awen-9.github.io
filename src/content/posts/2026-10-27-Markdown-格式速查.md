写文章时忘了某个写法，就来这篇找。每一节先给源码，点代码块右上角的 copy 就能复制，源码下面是它渲染出来的样子。

## 新文章模板

在 `src/content/posts/` 下新建 `年-月-日-名字.md`，把下面这段整个粘进去，改掉标题、日期和内容就能开写。可选的字段不用就删掉那一行。

````markdown
---
title: "文章标题"
description: "一句话摘要，显示在列表、搜索结果和 RSS 里"
date: 2026-12-31T20:00:00+08:00
# updated: 2027-01-05T10:00:00+08:00
category: "随笔"
tags: ["标签一", "标签二"]
# series: "系列名"
draft: true
---

开头一两段，说清楚这篇要讲什么。

## 第一节

## 第二节

## 第三节
````

`#` 开头的行是注释，构建时会被忽略，要用哪个字段就去掉前面的 `#`。写完准备发布时，删掉 `draft: true`。每个字段的含义见[《写一篇新文章》](/2026/10/27/写一篇新文章/)。

## 标题

```markdown
## 二级标题，会进左侧目录
### 三级标题，不进目录
```

正文从 `##` 开始用，不要写 `#` 一级标题，页面顶上已经显示了文章标题。至少三个 `##`，文章页才会出现目录。

## 文字

```markdown
**加粗**、*斜体*、~~删除线~~、`行内代码`。

段落之间空一行。只换行不空行，两行会连成一段。
```

**加粗**、*斜体*、~~删除线~~、`行内代码`。

## 链接

```markdown
[外部链接](https://astro.build)
[站内文章](/2026/10/27/写一篇新文章/)
[跳到本文的某一节](#代码块)
```

[外部链接](https://astro.build)、[站内文章](/2026/10/27/写一篇新文章/)、[跳到本文的某一节](#代码块)

站内文章的地址就是浏览器地址栏里 `/年/月/日/名字/` 那一段，末尾的 `/` 要带上。小节的地址可以点标题旁边的 `#` 复制。

```markdown

>

```

## 代码块

三个反引号开头，后面写语言名才有高亮，常用的有 `java`、`ts`、`bash`、`yaml`、`json`、`sql`、`xml`：

````markdown
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("hello");
    }
}
```
````

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("hello");
    }
}
```

不需要高亮的命令输出、日志写 `text`。代码块里本身有三个反引号时（比如这篇里展示代码块的写法），外面改用四个反引号包住。

## 表格

```markdown
| 参数 | 默认值 | 说明 |
| --- | :---: | ---: |
| corePoolSize | 0 | 核心线程数 |
| keepAliveTime | 60s | 空闲线程存活时间 |
```

| 参数 | 默认值 | 说明 |
| --- | :---: | ---: |
| corePoolSize | 0 | 核心线程数 |
| keepAliveTime | 60s | 空闲线程存活时间 |

第二行的 `:---:` 是居中，`---:` 是右对齐，`---` 是默认的左对齐。单元格里要写 `|` 时，写成 `\|`。

## 图片

```markdown
![图片说明](/images/2026-summary/books.jpg)
```

图片文件放在 `public/images/` 下，建议每篇一个文件夹，路径从 `/images` 开始写，不带 `public`。方括号里的说明在图片加载失败时显示，读屏软件也会念它，尽量写清楚图里是什么。

## 分割线和按键

```markdown
上一部分写完了。

---

按 <kbd>⌘K</kbd> 打开搜索。
```

上一部分写完了。

---

按 <kbd>⌘K</kbd> 打开搜索。

分割线 `---` 上面一定要空一行，紧挨着上一行文字时，那行文字会变成二级标题。`<kbd>` 是 HTML 标签，Markdown 里可以直接写 HTML。

## 复制到别的博客

这篇只用了标准 Markdown 和文件头，没有依赖这个博客的特殊写法。另起一个同样基于 Astro 的博客时，把这个文件复制到新博客的 `src/content/posts/`，改一下文件名里的日期，就能当作新博客的格式参考页。文中有两处链接指向本站的《写一篇新文章》，新博客里没有这篇的话，记得改掉或删掉。
